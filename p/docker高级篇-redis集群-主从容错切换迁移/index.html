Redis集群-主从容错切换迁移

Redis集群安装部署（Docker版）：[Docker]高级篇-Redis集群-3主3从

数据读写存储

启动6机构成的集群并通过exec进入

  • 进入redis-node-1容器
1

docker exec -it redis-node-1 /bin/bash

  • 进入redis
1

redis-cli -p 6381

  • 存储数据
1
2
3
4

set k1 v1
set k2 v2
set k3 v3
set k4 v4

可以看到(k1,v1)和(k2,v2)两组键值对无法存储，原因是超出了redis-node-1的哈希槽

防止路由失效加参数-c并新增两个key

  • 重新进入redis-node-1容器
1

docker exec -it redis-node-1 /bin/bash

  • 使用集群环境连接
1

redis-cli -p 6381 -c

  • 清空数据
1

FLUSHALL

  • 存储数据
1

set k1 v1

存储的数据在[12706]哈希槽，会自动跳转到该槽所在的节点。

1

set k2 v2


1

set k3 v3


1

set k4 v4

查看集群信息

  • 集群检查
1

redis-cli --cluster check 172.16.140.102:6381

容器切换迁移

主6381和从机切换，先停止主机6381

  • 查看集群信息
1

cluster nodes

  • 停止主机redis-node-1
1

docker stop redis-node-1

  • 查看运行的容器
1

docker ps

再次查看集群信息

  • 进入redis-node-2容器
1

docker exec -it redis-node-2 /bin/bash

  • 使用集群环境连接
1

redis-cli -p 6382 -c

  • 查看集群信息
1

cluster nodes

可以看到redis-node-1节点已经宕机，而redis-node-4节点从从机切换为了主机。

  • 取出数据
1
2
3
4

get k1
get k2
get k3
get k4

可以看到就算redis-node-1宕机了，其数据还是正常的。
