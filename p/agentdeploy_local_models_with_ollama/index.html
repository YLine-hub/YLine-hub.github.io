from langchain_community.chat_models import ChatOllama

# By default, use the model deployed locally with Ollama
ollama_client = ChatOllama(model="qwen3:8b")

resp = ollama_client.invoke("Who are you?")

Expose the port(Windows)

Expose the port so that machines on the intranet can access it.

  1. Set the environment variables

OLLAMA_HOST=192.168.3.69

Note: 192.168.3.69 is the internal IP of the Ollama server. If you want to allow access from any IP, use the wildcard address 0.0.0.0
