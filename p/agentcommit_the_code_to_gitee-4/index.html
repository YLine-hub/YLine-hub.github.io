Connect to Gitee

Install the plugin

Settings -> Plugins -> Gitee

Get a Gitee token

  1. Click your profile picture, then “Account Settings”

  1. Click “Private Tokens”

  1. Click “Generate New Token”

  1. After generating the new token, in PyCharm click “Settings” -> “Version Control” -> “Gitee”

  1. Click the “+” button and select “Log In with Tokens…”

  1. Enter the token and click “Add Account”

Upload the project

Create Git Repository

Click “VCS” -> “Create Git Repository”

Select the project direcotry and click “Open”

Open the directory containing the file

Enter the project directory

Use the shortcut “Command + Shift + .” to view hidden files

Add the .gitignore file to the project root direcotry

Commit

Right-click the directory, select “Git”, and click “Commit Directory…”

Write a comment and commit it to the local repository

Normalize line endings and commit (Execute “git config –global core.autocrlf input”)

  • Windows : Use CRLF (carriage + line feed, \r\n) as the line ending
  • Max/Linux : LF (line feed, \n) as the line ending

Click “Git” -> “Gitee” -> “Share Project on Gitee”

Write a description and push to the remote repository

Login authentication failed (Old authentication token)

Regenerate the token

Replace the Gitee account

Push again

View the remote repository
