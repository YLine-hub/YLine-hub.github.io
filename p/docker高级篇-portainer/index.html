2025-12-26

Portainer

介绍

Portainer是一款轻量级的应用，它提供了图形化界面，用于方便管理Docker环境，包括单机环境和集群环境。

安装

官网

官网网址：Portainer

安装文档：Linux-Install-Portainer

步骤

docker安装命令

  • old
1

docker run -d -p 8000:8000 -p 9000:9000 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer

--restart=always表示容器退出后总是重启容器

比如：使用systemctl restart docker重启容器，没有--restart=always的容器不会启动。

  • new
1

docker run -d -p 8000:8000 -p 9000:9000 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:2.33.6

第一次登陆，并创建admin(old)

  • 访问网址：http://宿主机IP:9000

  • 创建admin用户和密码

  • 登陆

选择local选项卡后本地docker详细信息展示(old)

  • 连接local本地环境
